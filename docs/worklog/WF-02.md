## Decisions taken
- `ci.yml` (push/PR to `dev`, `main`): a `gate-config` job reads `tools/versions.env` into job outputs (single source of versions), runs `scripts/check-versions.sh` (drift guard: a literal `go-version:` / `java-version:` in any workflow must match `versions.env`), then actionlint and shellcheck. The other jobs take `jdk`/`go` from those outputs: `java-build-test`, `server`, `docker`, `secret-scan`, `docs`.
- `server` and `docker` are skipped via job-level `if` on `gate-config` outputs (`has_server`, `has_dockerfile`), because `hashFiles()` is not available in a job-level `if`.
- `java-build-test` runs the full `./gradlew :core:compileJava :desktop:compileJava test`; ubuntu-latest ships an Android SDK, so the Android unit tests the local gate skips run here.
- `secret-scan` reuses `scripts/gitleaks-scan.sh range`: `before..sha` on push, `base..head` on PR.
- `docs` runs `scripts/md-sha-check.sh`, which is strict (no full SHAs) when `GITHUB_HEAD_REF` is `agent/*`, otherwise it verifies that every full SHA is reachable.
- `android-apk.yml`: push to `main` + manual; artifact `<appName>-<appVersionName>-<sha7>.apk`, with name and version read from the root `build.gradle` (characters outside `[A-Za-z0-9._-]` become `-`). Until BRD-01 it is `Shattered-Pixel-Dungeon-4.0.2-<sha7>.apk`.
- `ios.yml`: manual only, `macos-latest`, job `continue-on-error: true`. Steps: `:ios:build`, then `:ios:createIPA -Probovm.iosSkipSigning=true` (unsigned). No secrets. Expected to fail until a REL task works out the RoboVM setup: `docs/getting-started-ios.md` gives no recipe.
- WORKFLOW §7 also lists a `protocol-contract` job; it is not added (no protocol yet, and the BOOTSTRAP-01 prompt does not list it). PRO-01 should add it.
