## Decisions taken

- `tools/versions.env`: `JDK_VERSION=17`, `GO_VERSION=1.27.2` (current stable, released 2026-10-02), `GOVULNCHECK_VERSION=v1.8.0` (v1.9.0 is from 2026-10-11, younger than the 14-day pin rule), `GITLEAKS_VERSION=v8.30.1`, `ACTIONLINT_VERSION=v1.7.12` (added now so WF-02 does not need to edit `scripts/**`). Tool cache: `~/.cache/spd-coop-tools/`.
- `commit.sh` additionally validates the subject format of WORKFLOW §3 (`<TASK-ID>: ...`, `Merge <TASK-ID>: ...`, `docs: ...`).
- Gate-config changes (`Makefile`, `scripts/**`, `.githooks/**`, `tools/**`, `.gitleaks.toml`, `.github/**`) get a **gate scope** = every stage except `android`, instead of the SaaS repo's full gate. Reason: the full gate includes `:android:assembleDebug`, which needs an Android SDK; without this, no gate change could ever pass locally on a machine without the SDK. `make ci-full` and CI still run android.
- Java stage: `./gradlew :core:compileJava :desktop:compileJava test`. Without an Android SDK, `test` fails at configuration (`:android:testDebugUnitTest` needs the SDK), so the gate adds `-x :android:test` and prints a warning. CI always has the SDK.
- JDK selection: if `JAVA_HOME` is unset, the gate uses the JDK that provides `javac` on PATH. On this machine the default `java` (25) is a headless JRE without `javac`, so Gradle failed with "does not provide the required capabilities: [JAVA_COMPILER]".
- New stages beyond WORKFLOW §6: `versions` (drift guard, always), `shell` (shellcheck, gate scope), `actions` (actionlint, gate scope and `deploy/deploy.yml`). The `protocol` stage blocks if `docs/coop/protocol/fixtures` exists but is not wired yet (fail safe for PRO-01).
- govulncheck runs in text mode and blocks on any finding (exit 3), stdlib included. The SaaS policy filter (module-prefix based) does not apply here.
- `docker` stage compose validation (`scripts/compose-validate.sh`) uses `deploy/docker-compose.prod.yml` / `.dev.yml` as named in the BOOTSTRAP-01 prompt (WORKFLOW §6 said `docker-compose.yml`); the prod file is validated the way CI syncs it (`:IMAGE_TAG` substituted, `.env` from `.env.example`).
- `docs/coop/WORKFLOW.md` §6 updated to match all of the above.
