## Decisions taken
- Each action goes to its newest major that runs on `node24`, checked in each action repo via `runs.using` in `action.yml` at the major tag.
- Pin rule (14 days, `tools/versions.env`) applied to the major's first release (`vN.0.0`). Major tags float, so the current minor of a major can be newer than 14 days (table below).
- `create-github-app-token` keeps `app-id`: v3 still accepts it but marks it deprecated in favour of `client-id`. Switching needs a new secret (the App's Client ID). See Open questions.
- `deploy/deploy.yml` bumped too (same `actions/checkout@v4`). It runs on the self-hosted VPS runner, which needs runner v2.327.1+ for `node24`; a runner installed in OPS-01 part 2 will be newer.
